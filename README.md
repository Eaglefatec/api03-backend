# Server -  FLUXO ÚNICO DE SÁUDE E EXAMES - FUSEX - EXÉRCITO BRASILEIRO
API REST feita em Java usando o Spring Boot Framework para o [FUSex](https://github.com/Eaglefatec/api03.git)
# 🛠️ Pré-requisitos para rodar o projeto
-  **JDK 21+** - [Download](https://www.oracle.com/java/technologies/javase/jdk21-archive-downloads.html)
- **Docker Desktop** - [Download](https://www.docker.com/get-started/)
- **Git** - [Download](https://git-scm.com/downloads)
# 🚀 Passos para executar a aplicação
<ol>

<li>  <strong> Clone o repositório e navegue até o diretório do projeto </strong> </li>
  
```bash
git clone https://github.com/Eaglefatec/api03-backend.git
cd api03-backend
docker compose up -d
```
<li> <strong> Executar o projeto conforme seu sistema </strong> </li>

| Windows     | `.\mvnw spring-boot:run`                  |
| ----------- | ----------------------------------------- |
| **Linux/MacOS** | **`chmod +x mvnw && ./mvnw spring-boot:run`** |

</ol>
