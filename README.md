# Repositório do backend FUSEX

Este repositório preserva o caminho `fusex/` do projeto principal. O código Java, configurações, migrações, testes e arquivos de apoio do Maven ficam em `fusex/`. As páginas da interface ficam no repositório `api03-frontend`, em `fusex/src/main/resources/static/`.

Para executar o backend, entre em `fusex/` e siga as instruções do projeto principal. Ao integrar este repositório ao `api03`, mantenha o caminho `fusex/`.
